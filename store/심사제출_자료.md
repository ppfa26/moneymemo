# 경조사비 메모장 — 토스 콘솔 제출 자료 (최종)

- **앱 이름**: 경조사비 메모장
- **appName (config)**: `gyeongjosa-memo` ← 콘솔 앱 정보와 반드시 일치
- **버전**: 1.0.0
- **사업자**: 신주엽 / 597-12-02897
- **카테고리**: 생활 / 가계부·메모
- **수익 모델**: 인앱 광고(배너·전면·리워드)만. 인앱결제 없음. 완전 무료.

## 2. 한 줄 소개
누구에게·언제·얼마를 주고받았는지 기록하고, 엑셀·PDF로 정리하는 경조사비 기록 앱

## 3. 앱 설명 (스토어용)
결혼식, 장례식, 돌잔치… 축의금과 부조금, 매번 "누구한테 얼마 냈더라?" 헷갈리셨죠?
경조사비 메모장에 10초면 기록 끝. 주고받은 마음을 한눈에 정리해요.

- 받은 돈·낸 돈을 이번 달·올해 단위로 요약
- 이름으로 검색하고 종류·연도로 필터
- 청첩장·부고장·이체내역 사진 첨부(최대 3장)
- 엑셀·PDF로 내보내서 연말 정산까지

**사업자님께**: 거래처 경조사비, 비용처리 증빙이 고민이셨다면
기간별로 엑셀·PDF를 뽑아 경비처리 자료로 바로 쓸 수 있어요.

기록은 내 휴대폰에만 저장돼요. 연락처를 가져오지 않아 안심하고 쓸 수 있어요.

## 5. 최종 광고 배치 (심층 점검 완료)
| 광고 | 위치 | 비고 |
|---|---|---|
| **배너** | 홈 하단 · 목록 하단 | 상시. 입력/사진 화면엔 없음 |
| **전면** | 상세를 본 뒤 홈으로 돌아올 때 1회 | 콘텐츠 소비 후 전환 시점 |
| **리워드** | 엑셀·PDF 다운로드 시 | 자발적. 실패해도 다운로드 진행 |

**전면광고 안전장치**: 장례 기록 스킵 · 가입 후 24시간 유예 · 세션당 1회 · 5분 쿨타임
→ "기록 저장" 같은 핵심 액션 직후에는 광고를 넣지 않아 이탈을 막았어요.

- [x] 금지어 없음 (금융알선/대출보장/승인보장 미사용, "정부지원금" 미사용)

## 7. 최종 신청 절차 (대표님 진행)
1. **콘솔 앱 생성**: 이름 "경조사비 메모장", appName `gyeongjosa-memo`
2. **광고 슬롯 3개 발급** → 배너 / 전면 / 리워드
   - 발급 ID를 `src/ads/adConfig.ts`의 테스트 ID와 교체 후 재빌드
3. **알림 스마트발송 템플릿 발급** → 코드를
   `src/notifications/notify.ts`의 `NOTIFICATION_TEMPLATE_CODE`와 교체
   - 발송 예약: 경조사 D-1 / 월말 요약 / 명절·연말 정리
4. **빌드**: `npm run build` → `gyeongjosa-memo.ait` 생성
5. **콘솔에 `.ait` 수동 업로드** + 위 이미지/설명 등록 → 심사 제출

> ⚠️ 실제 광고 ID·알림 템플릿 코드로 교체하지 않으면 테스트 광고가 나가요.
> 출시 전 반드시 교체하세요. (교체 파일: adConfig.ts, notify.ts)
