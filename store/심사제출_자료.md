## 앱 설명 (스토어용)
결혼식, 장례식, 돌잔치… 축의금과 부조금, 매번 헷갈리셨죠?
경조사비 메모장에 10초면 기록 끝. 누구에게 얼마를 주고받았는지 한눈에 정리돼요.

- 받은 돈·낸 돈을 이번 달·올해 단위로 요약
- 이름으로 검색하고 종류·연도로 필터
- 청첩장·부고장·이체내역 사진 첨부
- 엑셀·PDF로 내보내서 연말 정산·경비처리까지

기록은 내 휴대폰에만 저장돼요. 연락처를 가져오지 않아 안심하고 쓸 수 있어요.

## 콘솔에서 직접 설정해야 하는 항목
1. 앱 생성: 이름 "경조사비 메모장", appName `gyeongjosa-memo`
2. 광고 슬롯 3개 발급 → 배너 / 전면 / 리워드
   - 발급받은 ID를 `src/ads/adConfig.ts`의 테스트 ID와 교체
3. 알림 스마트발송 템플릿 발급 → 템플릿 코드를
   `src/notifications/notify.ts`의 `NOTIFICATION_TEMPLATE_CODE`와 교체
   - 발송 예약(콘솔): 경조사 D-1 / 월말 요약 / 명절·연말 정리
4. `.ait` 파일 수동 업로드 (빌드: `npm run build` → `gyeongjosa-memo.ait`)
